# Phase 2 プロトタイプ測定 — ステム入力（stems 設定）

ハーネス: scripts/measureStems.ts（`npm run measure:stems`）。
構成: コード判定クロマ = other ステム、ベース低域分布 = bass ステム、
モード決め直し = other ステムの上帯域（既定 split の適応）。
キー／テンポは混合音から（Phase 1 と比較条件を揃えるため）。
正解・指標は Phase 1（measurements/real/*/truth.json、measureRealSong）と同一。
