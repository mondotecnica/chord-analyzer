# Q2 検証: キーボードステムの E♭ は実演か、ボーカルの滲み（リーク）か

> **対象**: 先行調査 [Q2_CM_INVESTIGATION.md](Q2_CM_INVESTIGATION.md) の
> 結論「キーボード（Rhodes 系）が E♮ を E♭ に差し替えて Cm 三和音を
> 弾いている」に対する検証（2026-10-29、ユーザー確認依頼）。
> Suno のステムは生成時のマルチトラックではなく完成ステレオへの
> 後付け分離であり、ステム間の滲みが原理的にありうる。そこで2仮説を
> 音響的に判別した。製品コードの変更は含まない。
> 生データ: [q2-cm-leak-check.json](q2-cm-leak-check.json)、
> 解析スクリプト: [scripts/q2CmLeakCheck.py](scripts/q2CmLeakCheck.py)。

- 仮説A（実演）: キーボードが本当に E♭ を発音している
- 仮説B（滲み）: キーボードは E♭ を弾いておらず、ボーカルの E♭ が
  分離の滲みとしてキーボードステムに現れている

## 結論

**仮説A（実演）が濃厚。** 滲みでは説明できない証拠が複数の独立した
観点で揃った。最も決定的なのは次の3点:

1. **滲み量の実測が2桁不足する**: ボーカルだけが装飾 E♭ を歌い
   キーボードが追随しない瞬間（150.51 秒／163.70 秒）では、
   キーボードステムの E♭4 帯域はボーカルの **0.76% 以下**（150.51 秒
   では 4.9×10⁻¹¹、事実上ゼロ）。この分離のクロストーク実測値では、
   イベント時のキーボード E♭（ボーカルピークの 43–70%、1.4 秒持続）
   は説明できない
2. **ボーカルが止んだ後もキーボードの E♭ だけが残る**: ボーカルの
   E♭ は 0.31 秒（N1）／0.28 秒（N2）で終わるが、キーボードの E♭4 は
   その後も滑らかに減衰しながら約1.4 秒持続する。153.75 秒では
   キーボード E♭4 絶対量 1.7×10⁵ に対しボーカル E♭4 は 2.4×10³ で、
   **「滲み」が源の約70倍大きい**ことになり物理的にありえない
3. **音色がキーボードのものである**: ボーカル E♭ が不在の区間で測った
   キーボード E♭4 の倍音列は、キーボード自身の E4 と同型
   （H2≈0.25–0.31、H3≤0.06 の急減衰列）で、ボーカル E♭4 の
   フォルマント型（H3＝0.20／0.79、H4＝0.19）とは全く異なる

したがって先行調査の結論は**維持され、確度は上がった**。先行調査では
「Basic Pitch の音符は推定であり単独では証拠にしない」と留保して
いたが、今回、音符抽出に依存しない絶対量・包絡・ピッチ軌跡・倍音の
各証拠が独立に同じ結論を裏付けた。

## 証拠の詳細

### 1. E♮ の絶対エネルギーはイベント中に消える（チェック項目1）

先行調査の「E♭ シェア上昇・E♮ 消失」は相対シェアだったため、
profiles.json の `powerDb` から絶対パワーを復元して再測した
（キーボードステム、E♮＝MIDI 40/52/64/76、E♭＝39/51/63/75 の合計）:

| 窓 | KB E♭ 絶対 | KB E♮ 絶対 | KB 総パワー |
|---|---|---|---|
| 直前 C 149.5–152.5 | 5.3×10³ | **3.53×10⁵** | 6.1×10⁵ |
| **N1 152.9–153.9** | **5.49×10⁵** | **2.70×10⁴（−92%）** | 7.4×10⁵ |
| 直前 C 164.0–165.6 | 1.78×10⁴ | **2.50×10⁵** | 6.1×10⁵ |
| **N2 166.0–167.3** | **4.74×10⁵** | **2.06×10⁴（−92%）** | 7.9×10⁵ |
| ev128 128.2–129.6 | 6.2×10⁴ | 2.5×10³ | 2.2×10⁵ |
| ev141 141.2–142.1 | 1.70×10⁵ | 1.0×10⁴ | 5.5×10⁵ |
| Am 参照 157.5–159.2 | 6.1×10³ | 1.48×10⁵ | 6.3×10⁵ |
| 中間 C 159.8–162.6 | 4.5×10³ | 2.49×10⁵ | 7.2×10⁵ |

滲みは信号を「加える」だけなので、キーボードが C メジャーのまま
弾き続けていれば E♮ の絶対量は残るはずだが、実測では両イベントとも
**約92% 消滅**し、総パワーは維持されている。「弾き続けたまま3度だけ
差し替わった」という実演の像と一致する。
（留保: 分離器のマスク処理が E♮ を間引く可能性は原理的にはある。
そのため本項目は単独では補助証拠とし、主証拠は項目2・3・4・6・7と
する。ただし間引きだけでは次項以降の E♭ の実在は説明できない。）

### 2. レベル比較: E♭ は「キーボードの通常の発音」の大きさ（項目3）

- キーボードの E♭ 絶対量（N1 5.49×10⁵／N2 4.74×10⁵）は、同ステムが
  直前に弾いていた E♮（3.53×10⁵／2.50×10⁵）を**上回る**
- 狭帯域ピーク（E♭4 基本波）でもキーボードはボーカル自身のピークの
  43%（N1）／70%（N2）に達する。ステム分離の滲みは通常、源に対して
  −10dB（パワーで10%）以下であり、43–70% が1.4 秒続くのは滲みの
  振る舞いではない

### 3. 対照実験: ボーカルだけが E♭ を歌う瞬間、キーボードに E♭ は現れない（項目4の前提＋滲み量の実測）

ボーカルの装飾 E♭（150.51–150.68／163.70–163.86）ではキーボードは
追随しないことが先行調査で分かっている。その瞬間のキーボード
ステム E♭4 帯域最大（STFT 狭帯域実測、パワー比）:

| 対照点 | KB E♭4 帯域 | VO E♭4 帯域 | 比 |
|---|---|---|---|
| 150.45–150.75 | 3.2×10⁻¹³ | 6.5×10⁻³ | **4.9×10⁻¹¹** |
| 163.64–163.92 | 1.0×10⁻⁴ | 9.0×10⁻³ | **0.0076** |

profiles.json のスライスでも 150.50 秒のキーボード E♭4 絶対量は
5.5×10⁻⁴（ボーカルは 7.1×10⁵）。**このセパレーションのボーカル→
キーボード間のクロストークは実測で1%未満**であり、イベントの
E♭（43–70%）を滲みで説明するには約2桁足りない。

### 4. 包絡線: ボーカルの音が終わっても減衰しながら持続する（項目2）

キーボード E♭4 帯域の、イベントピークに対するレベル:

| 時刻 | N1 | N2 |
|---|---|---|
| ボーカル E♭ 終了 +0.25s | −8.4 dB | −24.8 dB ※ |
| +0.55s | −13.0 dB | −6.9 dB |
| +0.85s | −16.9 dB | −16.3 dB |
| サステイン区間平均（N1 153.3–154.0／N2 166.45–167.3） | −12.1 dB | −11.9 dB |

※ N2 の +0.25s の落ち込みは一時的で +0.55s には −6.9 dB へ戻る
（トレモロ様の変調または再打鍵境界とみられる）。いずれにせよ
ボーカルの包絡（0.3 秒で消滅）とは無関係に、打鍵楽器の減衰として
約1.4 秒持続している。重なり区間の包絡相関は N1 で 0.75、N2 で
−0.68。同時アタックでは相関が出やすく単独の判別力はないが、
少なくとも N2 では包絡の形が追随していない。

### 5. ピッチ指紋: ボーカルのスクープは写っていない（項目2）

E♭4 部分音のセント偏差（重なり区間）:

| | 最初の100ms | 区間全体 |
|---|---|---|
| ボーカル N1 | **−18.3**（下からスクープ） | 平均 −0.6、σ14.6 |
| キーボード N1 | **+8.0** | 平均 +2.6、σ6.5 |
| ボーカル N2 | **−20.5**（スクープ） | 平均 −1.1、σ22.5 |
| キーボード N2 | 音符内部では **+2.7、σ1.5** と平坦 | サステイン部 +5.4、σ4.3 |

キーボードの E♭ はアタック直後からほぼ一定ピッチで、歌声の
スクープ／揺らぎの指紋は転写されていない。打鍵された実音の
振る舞いである。

### 6. 倍音構造: キーボードの音色で鳴っている（項目5）

基本波で正規化した倍音振幅（H1–H8、抜粋）:

| 対象 | H2 | H3 | H4 | H5 |
|---|---|---|---|---|
| KB E♭4（N1 サステイン 153.3–154.0） | 0.253 | 0.042 | 0.005 | 0.002 |
| KB E4（N1 直前 151.15–152.45、対照） | 0.313 | 0.015 | 0.004 | 0.0002 |
| VO E♭4（N1 152.78–153.03） | 0.176 | **0.198** | **0.193** | 0.021 |
| KB E♭4（N2 サステイン 166.45–167.3） | 0.103 | 0.057 | 0.003 | 0.0003 |
| KB E4（N2 直前、対照） | 0.241 | 0.020 | 0.001 | 0.0003 |
| VO E♭4（N2 165.89–166.11） | 0.302 | **0.789** | 0.157 | 0.045 |

キーボードの E♭4 は同ステムの E4 と同じ「H1 主体・急減衰」の列を
持ち、声のフォルマント帯（H3–H4 の隆起）を持たない。測定区間は
ボーカルの E♭ が不在の時間帯であり、その音色はキーボード側の
発音として記録されている。

### 7. 他ステムは対照として静か（項目4）

N1 窓の E♭ 絶対量: キーボード 5.49×10⁵ に対し、バッキング
7.2×10³（1.3%）、FX 6.3×10³（1.1%、ディレイ／リバーブ返りと
解釈済み）、ギター 約1.0×10²、シンセ／ストリングスはデジタル
フロア（この区間ほぼ無音）。滲み状の広がり自体は ~1% 級で確かに
存在するが、キーボードの E♭ はその約75倍あり、質が違う。
キーボード「だけ」に強く出る所見は実演寄りである。

### 8. 128／141 秒: 漏れる源が存在しない（項目6）

この2回では**ボーカルは E♭ を一切歌っていない**（音符キャッシュに
該当音高なし。128 秒は G4／B4 系、141 秒は G4／A4 系のライン）。
それでもキーボードには E♭3＋E♭4 が和声のアタックと同時に現れ
（E♭ 絶対 6.2×10⁴／1.70×10⁵）、E♮ は消えており、ev141 の
キーボード E♭ は自ピーク比 −8.4 dB で持続する。滲み仮説では
この2回の発生源を説明できない。4回共通の「キーボードのボイシング
型」として実演で統一的に説明できる。

### 傍証: 別の分離器でも同じ E♭ が立つ

先行調査で、Demucs（Suno の分離とは別方式）の other ステムでも
N2 に E♭ の立ち上がり（E♭ 0.346、比 0.84）が確認されている。
2つの独立した分離器が、同じ時刻に同じ音色・同じ持続の「滲み」を
作ることは考えにくく、ミックス自体にキーボード由来の E♭ が
含まれていることと整合する。

## 先行調査の確度への影響

- 結論（キーボードが E♭ を弾き、C・E♭・G の Cm 三和音が約1.4–1.6 秒
  実在した）は**変更なし、確度は上昇**した
- 変更されたのは根拠の構成である。先行調査の主根拠だった
  スペクトル・プロファイルのシェアと Basic Pitch 音符列に加え、
  本検証で (a) 絶対量での E♮ 消滅、(b) 滲み量の対照実測、
  (c) ボーカル離脱後の持続、(d) ピッチ指紋の非転写、
  (e) 倍音構造の同定、(f) 源の存在しない出現、が独立に揃った
- 「滲みかもしれない」という留保は、本素材の範囲では退けてよい
  と判断する。残る原理的な留保は Suno の分離器そのものの内部処理
  （未知の非線形処理）が全証拠を同時に偽装する可能性のみで、
  検証可能な仮説としては扱えない

## 方法メモ

- 絶対パワーは profiles.json の `detail`（シェア）× 10^(powerDb/10)
  で復元（FFT 32768・0.25 秒刻みのため時間方向に ±0.37 秒の
  なまりがある。窓平均の解釈にのみ使用）
- 細密解析はステム WAV（48kHz）をモノラル化し、STFT（4096点・
  hop 240 ≒ 5ms）で E♭4 基本波 ±9Hz の帯域パワーを追跡。
  ピッチは 120ms 窓・32768 点ゼロ詰め FFT のピーク補間
- 倍音プロファイルは 16384 点 FFT の窓平均スペクトルから
  各倍音 ±3.5Hz の最大値を抽出。キーボード E♭ の測定窓は
  ボーカルの E♭ が無く、ボーカルの他音（A4／B4 等）の倍音と
  E♭4 の倍音列が衝突しない時間帯を選んだ
- スクリプト: [scripts/q2CmLeakCheck.py](scripts/q2CmLeakCheck.py)、
  結果: [q2-cm-leak-check.json](q2-cm-leak-check.json)
