# Q2 調査: なぜ3つのツールは Cm と読んだのか — 音響的原因の特定

> **対象**: 「宵のひかり」Q2 通過部（05.mp3 の 153–168 秒。決着: Cm は棄却、
> 実態は Am→C）で、自アプリ stems 経路・Chord AI・Extrack の3者が Cm を
> 出した理由を音響的に特定する調査（2026-10-29、ユーザー依頼）。
> 製品コードの変更は含まない。生データは本フォルダの
> [profiles.json](profiles.json)（ステム別ピッチクラス・プロファイル）、
> [notes/](notes/)（Basic Pitch 音符キャッシュ）、
> [q2-cm-results.json](q2-cm-results.json)（集計サマリ）。

## 結論（機序の特定）

**Cm の印象は「聞こえの錯覚」ではなく、実在する短い Cm の響きが作っていた。**

1. 問題の2近傍では、**キーボード（Rhodes 系）のボイシングが E♮ を E♭ に
   差し替え、C・E♭・G の完全な Cm 三和音を約1.4–1.6 秒持続させる**。
   その間キーボードから E♮ は完全に消える（直前は E4 がステムの
   0.58–0.79 を占める強い C メジャー）。ベースは両イベントとも
   **C のペダルのまま動かない**
2. リードボーカルも同じ攻撃点で **E♭4 を正確なピッチ（+6 セント）で
   短く歌う**（0.28–0.38 秒）。これはボーカルに繰り返し現れる
   E♭→E の半音装飾モチーフの一員だが、この2箇所ではキーボードが
   その E♭ を「拾って」持続音に変えている
3. つまりこの箇所は、**C メジャーのフレーズ内部に埋め込まれた
   同主短調（パラレルマイナー）の色彩イベント**である。1–2 秒の窓で
   クロマ／テンプレート照合をする解析器にとって、その間の音高内容は
   客観的に C より Cm に近い。3者が揃って Cm と読んだのは、
   同じ実在の響きを拾ったためであり、偶然の一致ではない
4. この E♭ の響きは曲内で **約13秒周期の同じフレーズ位置に計4回**
   現れる（128.0 / 141.0 / 152.7 / 165.9 秒）。ただし Q2 以外の2回は
   ベースが B で、同じ音高クラスが **B の長3度（D#）** として機能して
   おり、Cm には読まれなかった（Baug／Bm 等に割れた）。**音高クラスは
   同じでも、ベースが C のときにだけ「C の短3度」になる**のが要点

ユーザーの仮説（メロディや上の音が短3度のように聞こえているだけかも
しれない）は半分正しい。メロディは実際に E♭ を歌っている。ただし
主因はメロディではなくキーボードのボイシングであり、しかも
「のように聞こえる」ではなく E♭ は実在し、持続し、音程も合っている。

## 方法と前提

- 素材: Suno 9ステム（stem-work/suno-yoi/src/、48kHz WAV）と合計
  ミックス、Demucs ステム（同曲・05 の両方）、05.mp3 本体。
  ステムと 05 は開始位置が一致（ラグ ≒ 0）するため、フィクスチャの
  時刻をそのままステムに適用できる
- ピッチクラス・プロファイル: プロジェクトのクロマ（FFT 4096・最近傍
  ビン割当て）の量子化誤差を避けるため、独自に FFT 32768 点＋セント
  空間の三角重み付けでピッチクラス／MIDI 別パワーを算出
  （scripts/q2CmProfile.py、44.1kHz 統一、0.25 秒刻み、80–200 秒）。
  パワー加重で窓集計した
- 音符レベル: Basic Pitch（nmp.onnx、従来の抽出スクリプト）を
  Suno ステム単体に初めて適用し、120–200 秒の音符キャッシュを作成
- 細密ピッチ追跡: ボーカルステムに対し 50ms 刻みのスペクトルピーク
  追跡（250–450Hz 帯）で E♭4 のピッチ軌跡を確認
- 注意: ステムは MP3 由来（ロスレスではない）。Basic Pitch は推定器で
  あり単独では証拠にしないが、本調査ではスペクトル・プロファイルと
  攻撃時刻が 0.01 秒単位で一致しており、相互に裏付けが取れている

## 証拠2: 音源への帰属

窓 N1／N2 で E♭ が有意に立ち上がるステムは次の通り:

- **キーボード（主因）**: N1 で E♭ シェア 0.670（うち E♭4 が 0.641）、
  N2 で 0.511（E♭3 0.134＋E♭4 0.362）。平常時の C 区間では 0.006–0.021
  しかなく、イベント時だけ 25–70 倍に跳ねる
- **ボーカル（副因・同時攻撃）**: N1 で E♭4 の基本波が単独 MIDI で
  最大級（0.202）。N2 でも E♭4 が立つ
- **FX**: N1 で E♭ 0.311。ただし音符は 153.45 以降の断片のみで、
  キーボード／ボーカルの E♭ のディレイ・リバーブ返りと解釈できる
  （発生源ではない）
- **バッキングボーカル: E♭ 音符ゼロ**（ハモリ説は棄却）
- **シンセ／ストリングス**: E♭ 音符ゼロ。ピッチクラス・プロファイル上
  E♭≈0.10 の一定値は全窓共通の残留成分（低レベルの滲み）で、
  イベント特異ではない
- **ギター**: この区間はほぼ無音（トレースレベル）。N2 に小さい
  E♭ 音符が2つあるが、ステム自体のレベルが低く主因たり得ない
- **ベース**: E♭ は無関係（後述の通り C ペダル）

## 証拠3: 音符レベルの性質判定

Basic Pitch の音符列（時刻は絶対時刻）:

**N1（152.7–）**
- キーボード: 直前 151.0–152.7 は C3・E4・G4・B3（CM7 系）。
  152.7 に **C3・G3・G4・E♭4** へ切替。E♭4 は 152.73–154.11 持続
  （約1.38 秒）、C4 も加わり、C・E♭・G の完全な三和音として鳴る。
  154.3 から E♭3 の短い尾、154.4 で Bm 系（B2・D4・F#4）へ
- ボーカル: …A4（151.4）→ B4（151.8）→ **E♭4（152.74–153.05）** →
  A4 → B4。メロディのフレーズ頭に E♭ が来る
- ベース: C2（151.0–152.3）→ G2（経過）→ **C2（152.7–154.3）** →
  B1（154.4、B m へ）

**N2（165.85–）**
- キーボード: 直前 164.2–165.1 は C3・E4（C メジャー）。
  165.9 に **C3・E♭3・E♭4・G3・G4**（E♭ は2オクターブ）で
  165.85–167.48 持続（約1.63 秒）。167.5 で Bm 系へ
- ボーカル: D4（165.7）→ **E♭4（165.85–166.13）** → A4 → B4
- ベース: **C2（165.8–167.5）** → B1（167.6）

分類（調査項目の選択肢に対して）:
- キーボードの E♭ = **(a) 持続する和声音**。ボイシングの3度そのものが
  E♮ から差し替わっており、経過音ではない
- ボーカルの E♭ = 短い旋律音だが、**細密ピッチ追跡では +6 セントの
  安定したプラトー**（152.75–152.95、312Hz）を持ち、スクープで
  入って A4 へ抜ける実音。(c) の「ベンド／ビブラートの通過点」
  ではない。なお同じモチーフの接近形（150.5 秒・163.7 秒）では
  ボーカルの E♭ はピッチが揺れる装飾的な動きで、キーボードは
  追随しない。**イベントの2箇所は「装飾の E♭ をキーボードが
  拾って和声化した」ケース**と読める
- (d) バッキングのハモリ構成音ではない（音符ゼロ）

ボーカルのモチーフ全体像（145–175 秒の抜粋）:
「A4–B4｜G4 G4 **E♭4**→E4 D4 E4｜A4–B4｜**E♭4** A4 B4」という
形が約13.2 秒周期で繰り返され、太字の2つ目の E♭ の位置で
キーボードの和声化が起きる（1つ目の E♭ は E4 へ解決する装飾）。

## 証拠4: ベースの構図

両イベントとも構図は **「C ベースの上に上声部の E♭」** で確定する。
ベースステムの低域プロファイルでは N1・N2 とも C シェア 0.65／0.76
が支配的で、音符列でも C2 がイベント全長を覆う。A のベースは
157.5–159.2（Am 参照区間）など別の場所にあり、イベント中に
ルートが A へ動くことはない。つまり解析器から見える構図は
「ルート C・3度 E♭・5度 G」の完全な Cm で、分数コード的な
食い違い（ベースだけ別のコード）でもない。

## 証拠5: 再現性 — 同じ音が B の上では長3度になる

キーボードの E♭ イベントは 80–200 秒で4回検出された
（E♭ シェア ≥0.15 かつ E♭/(E♭+E) ≥0.6 の持続区間）:

| 時刻 | ベース | キーボード E♭ | その音の機能 | ツールの読み |
|---|---|---|---|---|
| 128.0–129.75 | B（0.78） | 0.25（E♮ 0.01） | B の長3度（D#） | Baug／Bm／N.C. 等に割れた |
| 141.0–142.25 | B（0.81） | 0.31（E♮ 0.02） | B の長3度（D#） | Am／Bm 等（Cm なし） |
| 152.73–154.11 | **C** | 0.67（E♮ 0.04） | C の短3度（E♭） | **全員 Cm** |
| 165.85–167.48 | **C** | 0.51（E♮ 0.09） | C の短3度（E♭） | **全員 Cm** |

128／141 秒のキーボード音符列は B2・E♭3（・E♭4）・A3・D4・G4 と
ほぼ同一の型で、B メジャー系の響き（D#＝長3度）として鳴っている。
**同じ型の響きが、ベースと文脈で Cm にも B 系にもなる**。
Q2 の2箇所だけが「直前に強い E♮ の C メジャーが確立し、ベースが
C に留まる」条件を満たし、そのため短3度として最も際立った。

## 比較対照: 本物の短調と何が違うか

決着済みの本物のマイナーと比較した（キーボード、パワー加重）:

| 対象 | 3度の比（短／短＋長） | 3度の絶対シェア | ルート（ベース） | 持続と埋め込み |
|---|---|---|---
| Am 91–95（Q3 で決着） | C 0.110 vs C# 0.029 → 0.79 | 0.110 | A（0.521） | 約4秒・独立したコード区間 |
| Bm 154.4–156.0（隣接） | D 0.271 vs E♭ 0.106 → 0.72 | 0.271 | B（0.595） | 約1.6秒・進行の一部としてルートが移動 |
| **Cm イベント N1** | **0.95** | **0.670** | **C（不動）** | **約1.4秒・同ルートの C メジャーの内部** |
| **Cm イベント N2** | **0.85** | **0.511** | **C（不動）** | **約1.6秒・同上** |

皮肉なことに、**3度の証拠の純度だけなら Cm イベントは本物の Am より
「マイナーらしい」**（E♮ が完全に消え、E♭ がボイシングを支配する）。
本物の短調との違いは3度の強さではなく、文脈の側にある:

1. **ベース（ルート）が動かない**: 前後の C メジャーとルートが同一で、
   コード進行としての「移動」がない（Bm はルートごと移動する）
2. **同ルートの長3度が直前に強く存在する**: イベントの 0.1 秒前まで
   E4 がキーボードの過半を占めていた。コードが本当に Cm へ変わる
   場合は通常このような E♮ の確立は直前にない
3. **フレーズ内の固定位置に再現する装飾的パターン**であること
   （約13秒周期・4回。うち2回は B の長3度として機能）
4. 持続は約1小節強で、C メジャー区間全体（約12秒）の一部に留まる

## 過去の照合との関係（訂正の明記）

SUNO_05_ANALYSIS.md の Q2 照合は「Cm の決め手である E♭ は other
ステムで全スライス弱い（E♮ が2〜13倍）。**Cm の短3度は存在しない**」
を根拠に Cm を棄却した。今回の細密分析（0.25 秒刻み・量子化の無い
プロファイル＋ステム別音符抽出）はこの前提を**覆す**。旧照合の数値は
Demucs（05）other・5秒スライス・プロジェクトのクロマによるもので、
約1.4 秒のイベントが前後の E♮ に薄められたことと、ボーカルと
キーボードの分離ができていなかったことが主因とみられる。
実際、今回 Demucs other を細かく見ても N1／N2 で E♭ の立ち上がりは
確認できる（N2 で E♭ 0.346・比 0.84）。

ただし「153–168 秒の代表ラベルとして Cm を採らない」という**決着
自体**は、本書の証拠とも両立しうる。それは音響の有無ではなく
「フレーズ内部の短い色彩イベントをコード進行の1項として数えるか」
というラベル政策の判断であり、本調査の権限では変更しない。
根拠の文面（E♭ 不在）は維持できないことをここに明記する。

EVIDENCE_SELECTION.md が「Q2 の Cm 割合は音符証拠でも下がらない」
と記録していたことも、今回の結果で説明がつく。音符証拠が Cm を
支持したのは正しく、実際に Cm の構成音が鳴っていたためである。

## 規則候補の材料

将来「3度が曖昧なときに短調と断定しない」規則をテストするなら、
という依頼に対して: 本件の教訓は「3度が曖昧だったのではない。
**3度は明確に短3度だったが、それでもコードラベルとしての Cm は
（政策上）採らなかった**」である。したがって規則の条件は3度の
曖昧さではなく、以下の文脈観測量で書くべきだと考える:

1. **ルート不動条件**: 短3度イベントの前後でベースのルートが
   同一（本件: C）で、その同ルートの長調が前後に確立している
2. **長3度の隣接**: 同ルートの長3度（E♮）が、イベント開始の
   直前（本件は約2秒以内）に強く存在したか。存在すれば
   「コード変更」より「同一コード内の3度反転（色彩）」らしい
3. **持続比**: 短3度優位の持続時間が、同ルート区間全体に占める
   割合（本件: 約1.4–1.6 秒／約12 秒 ≒ 12–13%）と、小節数
   （約1小節強）。本物のコード交代（隣の Bm）も約1.6 秒あり、
   **持続時間単独では分離できない**点に注意
4. **由来の局在**: 短3度が単一のボイシング層（キーボード）と
   旋律装飾の同期だけで担われ、ベース・他の層が追随しないか
5. **再現位置**: フレーズ周期の固定位置に同型イベントが再現するか
   （本件は4回中2回が別ルートで長3度として機能）

規則の素描: 「ベースルートが不動のまま3度だけが反転し、直前に
同ルートの長3度が確立していた短い区間（目安: 1小節程度）は、
短調コードへの変更と断定せず、直前の長調を継続するか保留
（N.C.／候補提示）に回す」。これは本アプリの既存原則
（理論はソフトな prior のみ、否定フィクスチャの保護）とも整合する。

**未確定・注意点**:
- 本規則は「響きの忠実さ」ではなく「進行としての代表ラベル」を
  優先する政策であり、逆の政策（響き通り Cm と出す）も音響的には
  正当である。どちらを採るかは製品判断
- 本物の1小節だけの Cm（借用和音としての通過）も世の中には
  存在し、上記の観測量でどこまで分離できるかは未検証。
  テストするなら、本件のような「反転イベント」と本物の短い
  マイナーコードの両方のフィクスチャが要る
- Basic Pitch の音符は推定であり、特にキーボードの低音域
  （C2 等）には誤検出が混ざりうる。ただし本結論はスペクトル・
  プロファイル（音符抽出に依存しない）と一致している
- 128／141 秒の響きの正確なコード名（B メジャー系に色彩音を含む
  型）は特定していない。本調査の結論には影響しない
- Suno の生成過程でこの E♭ が「Cm コードとして」意図されたか
  「色彩として」意図されたかは、音声からは原理的に判別できない

## 追補（2026-10-29）: 「滲み」仮説の検証

本書の結論に対し、「キーボードステムの E♭ はボーカルの E♭ の
分離リークではないか」というユーザーからの確認があり、検証した
（[Q2_CM_LEAK_CHECK.md](Q2_CM_LEAK_CHECK.md)）。結論は
**実演が濃厚**で、本書の結論は変更なし・確度は上昇した。
決め手: (1) ボーカルだけが E♭ を歌う対照点ではキーボードステムの
E♭ 帯域はボーカルの 0.76% 以下（滲み量の実測）で、イベント時の
43–70% を説明できない、(2) ボーカルの E♭ が終わった後も
キーボードの E♭ が約1.4 秒、打鍵楽器の減衰で持続し、同時刻の
ボーカル E♭ の約70倍の絶対量になる、(3) 倍音列がキーボード自身の
E4 と同型で声のフォルマントを持たない、(4) 128／141 秒の出現では
ボーカルが E♭ を歌っておらず漏れる源が存在しない、(5) E♮ の
絶対エネルギーが両イベントで約92% 消滅する（滲みは加算のみで
既存音を消せない）。
