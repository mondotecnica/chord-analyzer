## 読み方

- 合成音源の数字（ルート 96.9% / 三和音 92.1%、PHASE1_UPPERBAND.md）は最易条件の上限。
  実曲で default が phase0 を上回れば、ベース補正＋上帯域が実曲でも効いていると言える。
- default が崩れて bass（全帯域）や band220 が良い場合は、帯域の最適値が実曲では
  違うということになる。その場合は固定値ではなく適応化が次フェーズの課題になる。
- hybrid（Phase 1.5 分業）は、ルートを bass 設定と同一手順（全帯域＋ベース補正）で
  決め、モードだけを上帯域 260Hz で決め直す構成。bass のルートと default の
  モード修正を両取りできるかが焦点（measurements/PHASE1_5_HYBRID.md）。
- conditional（Phase 1.5b 条件分岐）は hybrid に、崩壊シグネチャのあるセグメント
  だけルートも上帯域で決め直す分岐を足した構成（measurements/PHASE1_5B_CONDITIONAL.md）。
- 手順と判断基準の詳細は measurements/REAL_SONG_GUIDE.md を参照。
