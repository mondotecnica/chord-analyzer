## 1. 再設計の3本柱（STEP2.md §5 の具体化）

v1 の敗因は §4.3 で3つに切り分けられた: (1) emission の意味論
（負マージン＝集計の正の支持）が最大の増幅器、(2) キー項が
局所キー窓のノイズに無防備、(3) 遷移が現ラベル（とりわけ解決先の
主和音）を擁護しない。v2 はこの3点だけを作り替える。軸の重み・
上限・遷移表・候補列・Viterbi の骨格は v1 と同一に保ち、意味論の
変更の効果だけを測れるようにする。

### 柱1: floored の前提化（emission の意味論の作り替え）

- v2 の emission は、マージンが負の候補（集計だけなら勝者より
  優位な代替）に対して **0** を返す。集計の反対は「現ラベルへの
  支持が弱い」ことの表明に留まり、代替への正の証拠にはならない。
  代替が勝てるのは、その候補への理論項の合計が、柱3の現ラベル
  擁護（ホームアドバンテージ）を上回る場合に限る。
- 正マージン側（勝者が集計でも優位）は v1 と同一の扱い:
  接戦域 E = 0.06 の内側は額面、外側は逓減率 1/4 で数える。
  勝者の集計上の優位は従来どおり反転への抵抗として数える
  （非対称は意図的である: 勝者はフレーム列＋ベース証拠の複合
  判定の結果であり、候補スコアに現れない証拠を持つ。集計が
  勝者を支持する場合はその証拠と方向が一致するが、集計が
  反対する場合は「複合判定の見えない証拠」と「1視点の集計」が
  食い違っているだけであり、後者に独立した加点は与えない）。
- v1 の探索変種 emission-floored は、正マージン側も完全クランプ
  （逓減率 0）だった点だけが異なる。v2 は正側を v1 主構成と
  揃え、変更点を「負側の意味論」1点に限定する。なお v1 ハーネス
  の探索変種（逓減率 0 の floored）は、本変更後も再現できる
  （逓減率 0 では両定義が一致する）。

### 柱2: キー項の信頼度ゲート

- キー整合性（軸1）は、セグメントが属する局所キー窓の推定
  信頼度が閾値を満たす場合にだけ発言する。窓の
  **margin（最有力−次点の相関差）≥ 0.08 かつ correlation
  （最有力キーの Krumhansl 相関）≥ 0.74** を満たさない窓では、
  軸1の寄与は当該セグメントの全候補について 0（沈黙）になる。
  ハードゲートであり、重みの逓減はしない（監査可能性のため）。
  次点キーとの加重平均（v1 の仕様）は、ゲートを通った窓でのみ
  従来どおり働く。
- 閾値の根拠は §2 のプローブ（推定側の分布統計のみ、正解は
  見ていない）: 両統計量の pooled 中央値（margin 0.075、
  correlation 0.741）を丸めた値。「典型的な窓より確からしい
  窓でのみ発言する」という原則の具体化であり、発言する窓は
  全体の約 4 割弱になる見込み（プローブ実測 37% 前後）。
- 局所キー記録が無い場合（全体キーへのフォールバック）は
  ゲートを適用しない。全体キーは曲全体の集計による推定であり、
  窓単位の推定より信頼度が高い側の文脈だからである（v1 と同じ
  文脈を使い、沈黙させる理由がない）。
- ダイアトニック項（軸2）は全体キー基準であり、対象外とする
  （STEP2.md §4.3 の nodes-only の悪化は「とりわけ局所キー
  依存」と切り分けられており、柱2はその部分への対処である）。

### 柱3: 現ラベル擁護（遷移の両方向評価＋ホームアドバンテージ）

- 遷移項は Viterbi の経路評価として、挑戦者の経路と現ラベルの
  経路の双方に常に対等に効いている（これは v1 でも構造上そう
  であった）。v2 ではこれを明示の設計として固定したうえで、
  次の明示的な擁護を加える。
- **ホームアドバンテージ H = 0.005** を現ラベル（候補列の1位）
  のノードスコアに加算する。反転は「挑戦者の理論優位 − 勝者の
  集計優位（柱1の emission）」が H を上回る場合にだけ起こる。
  根拠: H は理論特徴の分解能から決める。キー適合は 1/3 刻みで
  あり、ノード証拠の最小量子は w_key × 1/3 = 0.005 である。
  H をこの量子に置くことで、「単一のキー適合1段差だけの優位
  （＝特徴の分解能以下の差）はノイズとして現ラベルを守り、
  それを超える理論の合意（複数軸・遷移の一致）がある場合に
  だけ反転する」という現状維持バイアスになる。勝者は候補
  スコアに現れない証拠（フレーム投票・ベース証拠）で選ばれて
  おり、同点・分解能以下の僅差では現状維持が保守的な既定で
  ある（設計書 §5 のタイブレーカー原則の、現状側への拡張）。
  Q3-Am の破壊（E7→Am の解決先を、emission の正の支持だけで
  Em／G に奪われた）は、柱1で集計側の加点を消し、柱3で解決先
  の現ラベルに遷移評価（V→I は遷移表で最大の +1.0）と H の
  両方が効く形にして防ぐ。
- **登録後の訂正（測定前に明記する）**: 本書の初版では H を
  swingCap の半分 = 0.03 と置いていたが、実装段階の設計整合性
  チェック（単体テストの構築時）で、この値は理論優位の現実的
  な到達範囲を超え、評価器を構成上ほぼ不活性化することに
  気づいた。理論優位の内訳は、遷移1辺の現実的な差が
  w_tr × 0.4〜0.85 ≈ 0.003〜0.006、ノード2軸の合計でも
  最大級で 0.015 程度であり、初回の成功事例（stems-05 の
  B7 回復）で実測された理論優位は +0.0069 だった。H = 0.03 は
  柱1の前提（理論項が揃えば代替が勝てる）と登録した関門 3b
  （B7 回復の維持）の双方を構成上到達不能にするため、精度
  測定を行う前に上記の分解能ベースの根拠へ訂正した。本訂正は
  評価スイートの測定結果に基づくものではない（この時点で
  精度測定は未実施であり、根拠は特徴の値域と初回実験の
  公開済み内訳のみである）。
- 後段ガード（生マージン ≥ swingCap の候補へは反転しない）は
  v1 から不変。N.C. の扱い（発明も消去もしない）、装飾つき
  セグメントの反転保護、根拠内訳（theoryRationale）の契約も
  v1 から不変である。

## 2. 較正の根拠（再掲と追加プローブ）

- マージン分布と swingCap の根拠は STEP2.md §2 のプローブを
  そのまま引き継ぐ（重み・上限は v1 から変えていない）。
- キーゲート閾値は、本再挑戦のために追加した真値なしプローブ
  （全測定スイートの baseline 解析から得た局所キー窓 578 件、
  正解ラベルは不使用、2026-10-29）による: margin の分布は
  p25 = 0.033／中央値 0.075／p75 = 0.135、correlation は
  p25 = 0.678／中央値 0.741／p75 = 0.796。閾値（0.08／0.74）は
  両中央値の丸めであり、評価スイートの正解で選んだ値ではない。
- H = 0.005 は §1 の訂正注記のとおり、理論特徴の分解能
  （キー適合の最小量子 w_key/3）からの構成的な導出であり、
  本再挑戦の評価結果を見て決めた値ではない。初回の成功事例の
  理論優位（+0.0069、STEP2.md §4.2 で公開済みの内訳）を
  下回ることは、柱1の前提との整合性の確認としてのみ用いた。
- 主構成は上表の1つだけであり、合否判定はこれだけで行う。
  報告にのみ添える変種（合否に使わない）: 柱の ablation
  （no-gate／no-home／no-floor＝v1 意味論＋他2柱）と v1 主構成
  の再掲。ablation は「どの柱が効いたか」の切り分け用であり、
  変種の結果をもって主構成の判定を覆すことはしない。

## 3. 事前登録基準（測定前に登録。この基準で判定する）

標本規約・Δ の定義は STEP2.md §3 と同一（0.05 秒標本、
labeled 基準、baseline は現行 top-1＝candidateRecord のみ）。
基準は初回と同等以上とし、Q3-Am の保全を独立項目に格上げする。

1. **非劣性（合成）**: 合成 A〜I 混合音の集計で root・triad の
   Δ が各 −1.0pt 以内。Song D ステムも同じ bound。
2. **改善（実曲）**: 実曲 1〜3 の集計で、混合音・ステムの両経路
   とも triad Δ ≥ +1.0pt、かつ root Δ ≥ −0.5pt、
   core Δ ≥ −0.5pt。
3. **フィクスチャ関門（ハード）**: Suno 05 両経路＋宵アーム B で:
   - **3a. Q3-Am 保全（独立項目）**: Q3-Am 窓（91–93 秒）で
     Am のラベル時間割合が全経路で baseline を下回らない
   - 3b. Q3-B7 窓（87–89 秒）: B major の割合が全経路で
     baseline を下回らず、かつ stems-05 では 34.0% 以上
     （v1 が回復した 68.3% の半分以上を維持する）
   - 3c. Q2 窓（153–168 秒）: Cm の割合が全経路で baseline を
     上回らない（棄却の維持）
   - 3d. Q1a（51–56 秒）・Q1b（93–98 秒）: C major の割合が
     全経路で baseline を下回らず、bassPc 一致率が baseline と
     同一。Q4 窓（62–65 秒）: C major の割合が全経路で
     baseline を下回らない
   - 3e. Q3-C（85–87 秒）・Q3-E7（89–91 秒）: 決着した読みの
     割合が全経路で baseline を下回らない
4. **Song D 混合音**: triad Δ ≥ +10.0pt。
5. **不変性と回帰**: theoryReevaluationV2 OFF（明示 false）の
   全スイート署名が baseline と一致し、v1（theoryReevaluation）
   の OFF/ON の挙動が初回測定（theory-step2-results.json の
   保存値）と一致すること。N.C. 時間が全スイートで baseline と
   完全一致（変動 0 を bound とする）。全テスト合格。

報告には必ず反転の内訳（変更セグメント数、標本ベースの
修正秒／破壊秒／両誤り変更秒）を初回と同形式で併記する。

**結論の置き方（事前に宣言する）**: 本再挑戦でも主構成が
基準 2 または基準 3a を満たさない場合、「候補列＋対数線形の
理論再評価」という本路線は、現行の証拠源（上帯域集計の候補
スコアと局所キー記録）の下では閉じることを結論とする。
その場合に路線を再開する条件は、新しい独立した証拠源
（例: 音符レベルの証拠、様式パックの外部統計）が評価器の
入力に加わることであり、重みや閾値の再調整では再開しない。

## 4. 結果

**総括: v2 主構成は事前登録基準を満たさなかった（基準 2・
3a・3b が不合格、基準 1・3c・3d・3e・4・5 は合格）。**
再設計は狙った機構どおりに効いた — 反転量は約 1/5 に減り、
合成は非劣性から明確な改善に転じ、Song D の利得は全量保持
され、v1 のフィクスチャ破壊（Q1b・Q3-C）は解消した。しかし
実曲では依然として差し引きマイナスであり、登録した2つの
ハードポイント（Q3-Am の保全、B7 回復の維持）を両方とも
落とした。§3 で事前に宣言したとおり、本路線は現行の証拠源
の下では閉じる（§5）。

### 4.3 柱ごとの寄与（ablation。合否には使わない）

実曲 triad（baseline: 混合音 26.0%／ステム 38.3%）:

| 構成 | 混合音 | ステム | 読み |
|---|---:|---:|---|
| v2 主構成 | 23.9 | 36.8 | — |
| v2-nofloor（柱1のみ外す） | 21.7 | 30.6 | floored が最大の損害削減要因。再び大きく悪化 |
| v2-nohome（柱3の H のみ外す） | 22.0 | 34.5 | H の擁護も実測で寄与 |
| v2-nogate（柱2のみ外す） | 22.9 | 36.1 | ゲートは集計では小幅に寄与。ただし stems-05 の B7 回復（68.3%）はゲートを外した場合にだけ戻る（4.4） |
| v1 主構成（参考） | 21.2 | 30.7 | nofloor とほぼ同水準 |

3本柱はいずれも損害削減に実測で寄与した（単独で外すと
全て悪化する）。それでも合計はマイナスであり、「部品は
全部効いているが、束ねても実曲では勝てない」が正確な
総括である。

### 4.4 残った失敗の診断（根拠内訳による監査）

- **Q3-Am の破壊は遷移項が駆動していた**（両経路とも）。
  stems-05 では Am（92.00–92.79 秒）が G へ反転し、根拠内訳は
  キー 0／ダイアトニック 0／遷移（前）−0.0004／遷移（次）
  **+0.0068** — 直後の C に対して G が「C の属和音（V/C）」
  と読めること（遷移表の二次ドミナント解決 +0.9）が駆動力で、
  E→Am の正格終止による擁護は、遷移が隣接セグメント側の
  局所キー文脈で評価される設計のため、この窓ではほぼ発現
  しなかった。混合音-05 でも同型（Am → G、遷移（次）
  +0.006 が駆動）。前提となる局所キー文脈はこの楽節で
  G major／C major と読んでおり（対象は A minor 系の進行）、
  **ゲートは低信頼の窓を黙らせるが、「自信を持って間違えた」
  窓（margin 0.12〜0.18、correlation 0.79〜0.85 でゲートを
  通過する）は止められない**。さらに遷移項は柱2のゲートの
  対象外であり（ゲートはキー節点項のみ）、誤った文脈は
  遷移経由では無防備に入る。これは柱2の設計境界として
  記録する。
- **B7 の回復が失われた理由も内訳で追える**。stems-05 の
  B セグメント（87.63–89.30 秒）が属する文脈窓は
  E minor（margin 0.047）でゲートにより沈黙した。その窓では
  B は属和音としてキー適合 1 を得るはずであり、柱2は正に
  ここで効くはずだったキー支持を消した。ゲートを外せば
  回復は戻り（ablation）、H を外しても戻る（キー支持なし
  でも B の理論優位は正だが H = 0.005 未満）。率直に言えば、
  v1 の B7 回復は emission の集計加点（逓減後も +0.19）が
  本体で、理論項（+0.0069）は追認にすぎなかった。「集計が
  構造的に正しい場面」を理論だけで再現することはできず、
  柱1で集計加点を捨てた時点で、この成功事例は設計上
  ほぼ失われることが本測定で確定した。
- つまり v1 と v2 の失敗は表裏である: 集計に追従すれば
  実曲の接戦で壊し（v1）、集計を捨てれば構造的に正しい
  集計の場面を取りこぼす（v2）。両者の間にあるのは重みの
  問題ではなく、**接戦域で集計と複合判定のどちらが正しい
  かを言い当てられる第三の証拠が、現行の入力に存在しない**
  という事実である。

### 4.5 回帰

全テスト合格（441 件合格＋1 スキップ。theoryReevaluation の
単体テストに v2 の 5 件 — floored の不発火、格上げ機構、
Q3-Am 型の保全、キーゲートの沈黙／発言、v2 構成の固定 —
を追加し、再挑戦の測定テストは基準5の構造項目と関門の
合否パターンを記録として固定した）。製品既定は不変
（theoryReevaluation／theoryReevaluationV2 とも明示
オプトインのまま）。

## 5. 結論（路線の閉じ方と再開条件）

- **v2 は不採用とする。** theoryReevaluationV2 は明示
  オプトインの実験構成として残置し、製品既定は変えない。
  v1・v2 とも履歴として再現可能に保つ（本測定で初回保存値
  との偏差 0 を確認済み）。
- **本路線はここで閉じる。** §3 の事前宣言どおり、基準 2
  （実曲の改善）と基準 3a（Q3-Am 保全）が再び満たされ
  なかったため、「第1段の候補列（上帯域集計のスコア）＋
  局所キー記録を入力とする、対数線形の理論系列再評価」は、
  現行の証拠源の下では閉じる。2つの独立した設計（広く
  追従する v1、保守化した v2）が、初回の剖検で特定された
  機構を全て直した後でも同じ基準で落ちた。拘束条件は
  評価器の設計ではなく証拠の質（接戦域における集計・
  局所キーの信頼性）にある、というのが2回の測定を通じた
  結論である。
- **再開条件**は、重み・閾値・上限の再調整ではない。再開は、
  評価器の入力に新しい独立した証拠源が加わる場合に限る:
  (a) 音符レベルの証拠（Basic Pitch のブラウザ推論は
  2026-10-29 に実測で関門を通過しており、候補の仲裁に
  クロマ集計と独立な信号を持ち込める）、または
  (b) 対象曲から推定しない様式パックの進行統計（設計書
  §7 第3段。本来の順序では次の段だが、単独では上記の
  拘束を解かない可能性が高いため、(a) との併用か、
  少なくとも実曲の非劣性と Q3 フィクスチャ対を最初の
  関門とする新しい事前登録をもって入ること）。
  いずれの場合も、本書の基準（特に 3a の独立項目と反転
  内訳の併記）を下限として引き継ぐ。
- **残る資産**: 第1段の候補露出は本路線の成否と独立に
  有効であり、今後の証拠源の受け口として維持する。
  theoryRationale の監査契約は2回とも有効に機能した
  （全ての有害な反転が項レベルで原因特定できた）。
  本書 §4.4 の失敗分類（自信を持って間違える局所キー
  文脈、文脈依存の遷移評価、集計の正しさを見分ける
  第三証拠の不在）は、将来の証拠源設計への入力とする。
