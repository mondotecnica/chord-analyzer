# Phase 3.1 測定土台 — 7th コード合成曲（Song E）ベースライン

測定日: 2026-10-31 / ハーネス: scripts/measureSeventh.ts

## 位置づけ

- PHASE3_PLAN.md §3.1（7th／テンション二段判定）の実装前に、現行アプリの
  「ビフォア」数値を固定するための測定。解析ロジックには手を入れていない。
- 解析条件はアプリの現行既定（bandStrategy "split"、ベース補正あり）。
  Phase 0 ベースライン（Phase 0 パイプライン固定）とは条件が違うため、
  数値を直接並べての優劣比較はしないこと。
- 正解の chord は三和音コア、fullChord が 7th を含む完全正解。
  現行語彙に 7th が無いため、完全正解率は構造的に 0% である。
  3.1 の合格基準は (a) コア正解率がここから下がらないこと、
  (b) 完全正解率が上がること（特に下表の Q3 型の小節）の 2 本立て。

## 3.1 への含意

- 上表で 7th 音が検出ラベルに現れないのは語彙の欠如そのものであり、
  故障ではない。3.1 はコア判定を壊さずにこの列を埋めることが仕事。
- 実曲 Q3（CM7–B7–E7–Am）と同じ並びを小節 1–4 に置いてあるため、
  合成曲での B7 の読みと実曲での B7→A の誤読を突き合わせられる。
